Terms of use

These terms apply to the hosted Sentinel service: the website, the API at sentinel-clawpump.vercel.app, the MCP server and the Telegram bot. By using them you accept these terms.

The service

Sentinel scores Solana tokens, builds and simulates transactions, applies policies you send with each request and returns a decision. It is free to use. The source code is open under the MIT license on GitHub; that license governs the code, these terms govern the hosted service.

Not financial advice

Scores, flags and decisions are automated risk indicators based on public on-chain and market data at the moment of the request. They can be wrong or incomplete. A token that scores well can still lose value or turn out to be a scam, and a decision to allow a transaction is not a recommendation to make it. You decide what to buy, sell or sign.

Your keys and your transactions

  • Sentinel never asks for, receives or stores private keys or seed phrases. It returns unsigned transactions.
  • You and your agent are responsible for what you sign and send. Verify transactions before signing; the official SDK does this locally by default.
  • For guarded wallets, the multisig is created on-chain with you as the owner holding every permission. Sentinel's key can only vote. You can withdraw funds or remove the agent without Sentinel.
  • Blockchain transactions are final. Sentinel cannot reverse, cancel or refund them.

Build your agent so that an error or timeout means "do not sign".

Public decision log

Decisions made through the API are recorded with the wallet address and are readable by anyone through /api/journal. Do not use the hosted service for wallets you need to keep unlinked from this activity. See the privacy policy.
